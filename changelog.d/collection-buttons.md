**A collection can put its own buttons on its records.** A button made on the Wires page, or by a bundle, can have its own name, fixed settings, and one question it asks before it runs, such as a tasting note when you open a bottle. Use one now keeps that note, dated, in the record's history, and an app's total can multiply by a count, so a value counts every unit.

## docs

On the **Wires** page, a wire whose trigger is *button* can now have its own **Button label** and can **Ask before running**: pick one of the action's settings and write the question. Pressing the button shows the question with a Cancel; leaving it blank still runs the action.

Settings you fill in for the button are fixed for it. For example, *Add to a list* with the list set to "Shopping list" and the label *Buy again* puts the record on that list in one tap, on that collection only.

**Use one** can take a note (how it tasted, what it was for). The note is kept on the line for that use in the record's **History**, with its date, so the next use never replaces it.

In an app, a **stat** that adds up a field can multiply each record by another field first: the value of what you hold is *price × how many*, not the price of one of each.
