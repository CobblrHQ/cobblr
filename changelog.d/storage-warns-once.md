Notifications from a sweep arrive as one message instead of one per item. Filing
a shop, a batch of things going out of date, several machines due for
maintenance and a run of buy-less advice each used to send a separate
notification per row, which made a stocked workspace a stream of them. Each is
now a single combined message. Putting groceries in a Kitchen that contains a
Fridge is no longer read as the wrong place, a freezer item somewhere warm is
the only one of these sent straight away, and the buy-less advice names the item
it is about instead of saying "this".
