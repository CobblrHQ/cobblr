The fleet view now works like an operator's tool: the summary counts became clickable buckets (All / Working / Needs you / Idle / Off), tiles say why a machine is blocked and what it will print next, running tiles show time-remaining and a "~done" clock, a Compact mode fits several times more machines per screen, you can select machines and pause/resume/stop/clear-bed them in one batch, and a library file can be dragged straight onto a machine tile to print it there.
