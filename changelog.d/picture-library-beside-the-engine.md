**A second place to get a picture from, and an honest message when the first one refuses.** Fresh produce now gets its catalog picture from the Wikimedia Commons photo library first, so "roma tomatoes" comes home as tomatoes and never as a tin, and the library also steps in for packaged goods when the web image search refuses to answer. The photo-options strip asks both sources, and when the web search is rate-limiting it says so ("web image search is rate-limiting us right now, try again in a while") instead of claiming nothing exists for your item.
