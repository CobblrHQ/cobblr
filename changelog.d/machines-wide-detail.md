**Machine details open wide, photo-left, matching the new record layout.** A machine's detail modal now uses the same two-column shape as assets: the photo large on the left (with the web photo search right under it), fields and panels on the right, so a printer or tool record uses the width of the modal instead of scrolling tall. Stacks back to one column on phones.
