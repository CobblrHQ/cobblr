Ask Cobb can tidy up for you. It can merge two tags that mean the same thing,
clear the done items off a list, and refresh a catalog from the source it was
built from. All three were things you could do by clicking and Cobb had no way
to do at all.

## docs

Ask Cobb to merge one tag into another and everything carrying the first ends up
carrying the second, with the first removed. Ask it to clear the done items from
a list and the ticked ones go, leaving the rest. Ask it to refresh a catalog and
it re-fetches from the source URL the catalog was built from; a catalog built by
importing a CSV has no source to refresh from and Cobb says so.
