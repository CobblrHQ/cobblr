Run several shop machines through one bridge, discover nearby controllers, and use a tablet as each machine station.

## docs

Connect networked machines through Cobblr Server's optional server bridge. For
USB machines, install one bridge on a Pi or an existing Linux, Windows or macOS
computer. Cloud Cobblr needs a bridge on the shop network. Find machines under
Configuration → Devices, then name each machine and authorize its station.
Install the station on a tablet and keep its screen awake during jobs. Desktop
Chrome or Edge also offers direct Web Serial for one GRBL laser; keep that tab
open and use a bridge for long jobs. See [Set up your shop](operations/set-up-your-shop.md)
for the three deployment pictures, USB permissions and setup instructions.
