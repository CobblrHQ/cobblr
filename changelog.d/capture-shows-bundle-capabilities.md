**Capturing an item into a capability-rich bundle now shows what it can do.** Type "lego set" into *Add your first thing* and the matchmaker's **Create** button used to install the bundle with its defaults and file your item silently. Now, when the bundle carries optional capabilities, Create opens the same chooser the recipe path uses so you pick what it does first, then your captured item lands in the tracker it builds. Bundles with nothing to choose still create in one tap.
