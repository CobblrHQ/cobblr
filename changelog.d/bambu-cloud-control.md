**Experimental cloud control for Bambu.** From a Bambu's fleet card you can now toggle the chamber light or nudge Z over the cloud connection — no LAN setup. It rides the same MQTT the pump already holds (the broker the Bambu app uses). It's a safe, visible way to test whether the printer accepts our commands; if it does, full pause/resume/stop over cloud follows.
