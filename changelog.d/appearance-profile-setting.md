**Appearance is now an explicit setting** in **Profile → Appearance** — **Match device · Light · Dark**. Before, the only way to change theme was a session toggle (an icon that's hidden on branded workspaces), and it only saved a preference if you happened to hit it — so if you never did, each device just followed its own OS and two devices could disagree ("dark on my Mac, light on my phone"). Now picking **Dark** (or **Light**) makes that choice explicit and it follows your account to every device, overriding each device's OS; **Match device** is a deliberate, saved choice that follows each device's OS live. Persists per-account, unchanged for other members, and a workspace with its own branded theme still shows that theme.
