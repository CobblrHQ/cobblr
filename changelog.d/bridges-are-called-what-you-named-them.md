**Your bridges are called what you named them.** The name you type when you set up a bridge is the name every screen uses, and you can rename it on the bridges page. Each bridge shows whether it is online, when it was last heard from, the machine it runs on and its version, and it stays listed while it is offline. A form that sends through a bridge picks your only bridge for you, lists several by name, and offers to set one up when you have none.
