Setting up a tracker is smoother. The **"what do you want to keep track of?"** search now tolerates typos — *"pprint"* still finds 3D Printers, *"machne"* finds Machines. And picking a ready-made tracker no longer pops a second *"enable this module?"* dialog — Cobblr enables what the tracker needs and installs it in one step.
