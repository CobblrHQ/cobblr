Fill in a whole collection's missing pictures in one press. When some records have no image, the collection header offers a "fetch N missing images" button that looks each one up the same way a single record's Auto does, using what the record actually is (its name plus its own author, director, or artist). It only touches records with no picture, so one you chose yourself is never overwritten and pressing it again simply continues where it left off. Images arrive one at a time and the list refreshes as they land.
