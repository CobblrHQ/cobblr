Added NFC stations that file scanned things into a place, write or link tags from any phone, and let you review and undo a session.

## docs

### Put things away with a station

Open Scan inbox, then Scan stations. Add a station, choose File, and copy its ID
into the relay setup portal with your workspace API token. Scan a place first,
then the things that belong there. Scan a holder twice in a row to put things
inside it. Scan a place to leave the holder.

A short station-button press undoes the last action. A long press ends the session.
Ten idle minutes end it too. Open the session notification to review each move
and undo one line or the whole session. Undo keeps any later manual move.

On a record's Copy tag link page, choose Write to a tag or Tap to link and tap the
next tag at your station within five minutes. The station writes or links the tag,
so either option works from iPhone. The station page also offers printable mode,
undo and end controls, and can write those controls to tags.
