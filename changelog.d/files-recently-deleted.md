Deleted files now go to Recently deleted for 30 days, where you can restore them or delete them forever, and after that they are removed from disk for good.

## docs

**Recently deleted.** Deleting a file on the Files page moves it to Recently deleted, at the bottom of the page, and the message that says so has an Undo. A deleted file stays there for 30 days and shows how long it has left. Restore brings it back to the folder it was in. Delete forever removes it at once. After its 30 days it is removed for good, bytes and all, so a photo you deleted does not stay on the server. You can also ask Cobb to bring back a file you deleted.
