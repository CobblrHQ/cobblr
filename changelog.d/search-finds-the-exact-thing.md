**A serial or a code finds its thing from every search box.** Only the command palette used to put an exact identifier first; the header search and the search page now do too, marked "Exact match". In the header search, the arrow keys move through the results and Enter opens the one you are on. The search page offers only the kinds a search can actually reach, and picking one on its own lists it. Screen readers now hear which result the arrow keys are on in the palette and the header search.
