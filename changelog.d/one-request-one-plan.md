**One request to Cobb is one plan with one Confirm.** "Delete this and Yarn as a whole" used to come back as separate cards, one of which kept the records you asked to remove and still counted the one the first card deletes. Now it is one card with its steps in order, each worded after the ones before it and saying whether it can be undone, and one Confirm that runs them all. An earlier card about the same thing folds away as replaced, so there is never more than one Confirm for what you asked.
