Connection forms no longer get your saved login filled in. Chrome filled your account email into server addresses and your password into API tokens on forms like Import from Part-DB; API keys, tokens and device passwords are now masked fields no browser takes for a login, and server addresses are address fields. Choosing Default bridge in Import from Part-DB or Homebox now lets you connect, and a greyed Connect button says what is missing.
