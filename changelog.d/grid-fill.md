**Fill a parts rack with one grid.** A layout's edit mode gained **+ grid**: rows × columns and a naming scheme (A1…C8 or Bin 1…24) create and place a whole set of bins at true scale in one shot; a 24-bin rack stops costing 24 modals. ## docs

In a layout's edit mode, **+ grid** takes rows × columns and a naming scheme (A1…C8, or a prefix like "Bin 1…24") and creates *and* places the whole set at true scale in one shot. Each bin is an ordinary location afterward: scan it, label it (the Labels page prints the whole set), drop parts in it, see it on the heat view. Works on any layout: a rack's face, a cabinet, even floor cubbies on a plan view.
