You can reorganise lists, choose where unmatched scans land, add several items together, recheck scan matches and undo a past inbox import from the app.

## docs

Use **Configuration → Presentation → Organise** to give a category its own list, fold a list into another of the same kind, or send unmatched scans there. List moves keep the records and offer Undo.

Use **Add several** with the inventory list's import tools to enter one name per line, up to 100, in the current list. Each starts at quantity one with the list's default unit.

A pending scan's **More item tools → Recheck matches** checks the current lists again. **Import from file → Recent imports → Undo import** lets an owner or admin reverse a past run after confirmation. Reversal removes added items and restores replaced items, including overwriting any later edits to those items.
