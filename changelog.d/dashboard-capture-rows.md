The dashboard groups captures into compact rows with photos, expandable duplicates and an Add all button for each collection.

## docs

**What you've added** groups typed captures by their suggested collection.
Each compact row shows a photo or collection icon, its name and an Add button.
**Add all** files every capture counted in that group. If the collection does
not exist, the group says it will be created first.

Repeated names in the same collection fold into one row marked **×2** (or the
actual count). Expand the row to add, open or dismiss either capture. The
collapsed dismiss removes one capture. For two sightings of the same physical
thing, **Same item? Merge** combines them through the inbox's reversible merge
flow. Cobb can file the same selected captures into a collection.
