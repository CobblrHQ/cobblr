Creating a location while filling out a form no longer pops a second modal — "+ new location" now expands as an accordion right inside the form you're in. Kind is a two-button pick (Container / Area) instead of a dropdown, and a container you name "Bin" (or "Shelf", "Drawer") gets a globally-unique number appended automatically — "Bin 17" — so every container has a unique label/scan number.
