Scanned and receipt-entered items now arrive with a suggested spot, and filing
a batch puts them there. Anything that has to be kept cold is offered the
Fridge or Freezer even in a brand new workspace, which is when the old
suggestion stayed silent, because it could only learn from where similar items
already lived. Where the two disagree, how a thing has to be kept wins: three
yoghurts sitting in a cupboard no longer teach it to put the fourth there. The
File all button names where things are about to go before it does it.
