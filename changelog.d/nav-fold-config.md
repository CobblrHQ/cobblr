**Sidebar mode never stacks two sidebars.** With navigation in the left sidebar, opening Configuration used to add a *second* sidebar beside the first. Now the main sidebar simply **becomes** the configuration panel: hub link, settings search, and every grouped destination fold into it, with a quiet "← workspace" row to swap back, and the settings page gets the full width. Leave the configuration area (or flip back to the top bar) and everything returns to normal.
