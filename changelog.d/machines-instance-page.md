A machine type with its own tab (3D Printers, Laser Cutters, CNC Machines) now opens the full machine page — set every field, edit, attach files, and link the machine straight to its print manager (FDM Monster/OctoPrint) from its own page — instead of a name-only stub. Installing one of those bundles also offers a checked-by-default "Connect to your machines" option that brings the Print Manager along.
