**The activity log now records a list you make and a scan you file.** A table or list made by hand (or by promoting a category into its own table) and every scan you file are in the workspace's activity log as what they are, with the table it went to, the name and the pictures, so what you did in a workspace can be read back later as "made a Spices list", "scanned six things".
