**A task has a checklist.** Open a task to list the small steps inside it and tick each one off as you go. The task's line on the project shows how far along it is, like 2/5.

## docs

**Checklist** in a task holds the small steps inside it ("buy tiles", "mix grout", "seal"). Type a step and press Enter to add it, tick it when it is done, and use the cross to remove it. The task's line on its project shows how many are done, like **2/5**.
