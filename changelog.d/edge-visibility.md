**Edge bridges get a home.** Configuration → Edge bridges shows every on-site bridge in one place: which relay agents are connected right now (last poll, in-flight work), every machine manager running through a bridge with its health and a Test-now button, and how to set a new one up: direct-LAN or cloud relay. And **search now finds Cobblr itself**: type "edge bridge" (or scan, build, calendar, backup, tokens…) into ⌘K or the header search and jump straight to the feature, not just your data.
