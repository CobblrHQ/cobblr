You can now mark a discussion settled (and reopen it later), and edit your own comments, straight from the Discussion tab and the Discussion inbox.

## docs

**Settle a conversation, or open it again.** When a discussion has run its
course, mark it settled: a check button in the Discussion tab's header (and on
each row of the Discussion inbox) closes it, and a "settled" tag shows on the
record and in the inbox so everyone can see it is done. Reopen it the same way
if it comes back up. Settling is open to members and up; a guest sees that a
conversation is settled but does not change it.

**Edit your own comments.** A pencil sits next to Delete on a comment you wrote.
It opens the comment inline so you can fix a typo or reword it; press Save (or
Enter) to keep the change, Escape to cancel. An edited comment carries a small
"edited" note, and any reply that quotes it says "edited since this reply" so a
recorded "agreed" is never quietly attached to different words. You can only
edit your own comments, never someone else's, and Cobb's answers are not
editable.
