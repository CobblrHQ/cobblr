An action you bound to a kind now appears on every row of that kind, not only on each record's own page. Bind label printing to everything physical once and every row has a Print label button.

## docs
Actions you bound to a kind ride the rows. Say once that printing a label applies to everything physical, and a Print label button appears on every one of those rows, not only on each record's own page. A module's actions that you have not bound stay on the record's page, where there is room to explain them; up to three of your own bound actions show per row. Anything that cannot be put right again asks before it runs, because a row button sits between an edit pencil and a delete bin: the first tap says "sure?" and the second one does it.
