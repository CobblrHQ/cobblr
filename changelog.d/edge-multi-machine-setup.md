The edge-bridge setup now configures **one bridge for all the machines at your site**. It clearly frames the first machine, and **+ Add another machine** lets you put several on the same bridge (each with its own driver + IP) — it generates one run command and creates a connection per machine. Plus: the multi-step connect modals now have a clear **← Back** to the previous step, and **Cancel** exits the whole dialog (it used to quietly go back, which was confusing).
