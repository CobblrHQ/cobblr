The floor plan editor has undo and redo. The arrows beside Done, or ⌘Z and ⌘⇧Z, take back a move, a resize, a new wall, a rename, a set of added drawers or a whole drafted plan, one change at a time, and put it back again.

## docs

**Undo and redo on the plan.** While you edit a layout, the arrows beside
**Done** take back the last change and put it back again. The keyboard works
too: ⌘Z and ⌘⇧Z on a Mac, Ctrl+Z and Ctrl+Shift+Z (or Ctrl+Y) elsewhere. A key
press inside a text box undoes the text instead.

Every edit counts: moving or resizing something, dropping it into another bay,
taking it off the plan, walls and the outline, colours, renaming, adding places
or a set of drawers, and a plan drafted from a description, which comes back as
one step. Undoing an add deletes the places it made, and redoing it brings the
same places back, so their labels still work. Hover an arrow to see what it will
undo. The last 50 changes are kept until you reload the page.
