**A book has one Print label, and it prints the book.** A Bookshelf book showed two identical Print label buttons: one queued the title alone, the other queued "Unknown / title / ?" with a second QR that the scanner offered to file things into. There is now one button, it uses the collection's own label (author, title, year), and the QR opens the book. Every shipped label that names a bundle's field (a Lego theme and set number, a fastener's thread and length, a tool's maker) now prints the value instead of its placeholder. A label already printed the old way still opens its record.
