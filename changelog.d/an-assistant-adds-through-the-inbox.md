## docs

**Things an assistant adds.** When Cobb or an assistant you connected (through
MCP) adds something you own, a printer, a book, a spool, it goes through the
same intake as a scan. It checks for one you already have, picks the table and
category, fills the fields the name, code or link tells it, and adds a picture
and a place. It then tells the assistant which fields are still empty, so it
can ask you rather than guess.

What it adds lands in your scan inbox marked **from your assistant**. The
assistant can file it right away, or leave it there for you to look over and
file like any other capture. If you already have the thing, it is not filed a
second time: it waits in the inbox and the assistant is told which record is
already there.
