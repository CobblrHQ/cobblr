Adding a machine to a bridge you already run is now obvious: if your edge bridge is online, the setup skips the install steps and goes straight to "add a machine", so you can plug a Bambu (LAN), Prusa, Klipper, etc. into your existing bridge without reinstalling. Also: in the pool machine picker, the printer name now gets priority over the connection it's on (no more "Thum…").
