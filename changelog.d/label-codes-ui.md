Label codes now show everywhere you work with labels, not just on the printout. The on-screen preview and the browser (⌘P) print sheet draw the code in each QR center, every queued row shows its code as a chip, and a new Codes button lets you find an item by typing its code, rename a list's prefix, or change what a kind's codes group by.

## docs

- **Codes in the preview and on ⌘P prints.** The center code now appears in the live sheet preview and the browser print sheet, not only on the direct-to-printer path. Those QRs render at high error-correction so the code stays scannable.
- **A code chip on every queued row.** Each item in the print queue shows its assigned code, so you can see what will land in the middle of its label before you print.
- **The Codes button.** Opens a panel to find an item by typing its code (case- and typo-tolerant, jumps straight to the item), rename a list's prefix (until its first label prints, after which it's locked), and change what a kind's codes group by.
