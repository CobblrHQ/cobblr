**A board reads in its field's order.** A board grouped by a field with set values, such as a machine's state or any dropdown field, now lays out its columns in that field's order instead of alphabetically, and keeps a column for a value with nothing in it, so a fleet board shows Rebuilding at 0 rather than no Rebuilding at all. Records with no value come last, under No value.
