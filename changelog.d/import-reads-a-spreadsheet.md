The import API can now read a spreadsheet (.xlsx, .xls, .ods, .csv, .tsv, or a shared Google Sheets link) and tell you what it holds without changing anything: the header row under any title, what each column is, which column names each thing and which says where it is kept, and every row it would leave out and why.
