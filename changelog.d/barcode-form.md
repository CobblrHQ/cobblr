New item forms can scan a barcode to fill empty details and a photo, keep what you typed, and show when you already have the item.

## docs

**Scan while adding an item.** When a new item has a barcode or identifier field, choose **Scan to fill** to read it with your camera, or scan it with a USB scanner while the form has focus. You can also type the code and choose **Look up barcode**. The code goes into the field, then the lookup fills empty details such as the name, brand, model, category and photo. Values marked **from barcode** came from that lookup. Check them before saving; anything you already typed stays as it is.

If no catalogue knows the code, the form says so and keeps the barcode. Fill in the name and carry on saving. If the code is already in your workspace, **Open it** takes you to that record. Choose **Add one more** only if you want to create another record for it. Looking up the barcode adds nothing to the scan inbox. Cobb can answer the same lookup when you ask, “What is this barcode?”
