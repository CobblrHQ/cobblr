## docs

**A file's own page.** Every file opens on its own page, from search, a tag, a saved view, a link Cobb gives you, or the ⓘ beside it on the Files page. It shows the file itself (an image, or a PDF or model when Cobblr can show it, otherwise a button to open it), its size, when it was added and its folder. **Used by** lists every record the file is attached to, each one a link, with the part it plays there, such as main photo or manual. You can rename, move, open or delete the file from the page. A deleted file goes to Recently deleted.
