**Match a new set or part to the catalog as you create it.** The new-item form now shows a "Match to a catalog" search on catalog-backed instances (Lego Sets, where it used to be hidden), and that search now reaches hosted catalogs. Type a set name or number, pick the Rebrickable entry, and the new set is linked to it, so its theme, year, pieces, and photo come along without typing them. Instances with nothing to match against stay clean, and scanning still auto-matches the same way.
