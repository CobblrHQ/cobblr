Cobb can switch a whole set of fields on across everything it applies to ("track where my things came from"), and rename a heading on a form.

## docs

Some fields belong together and go on in one go. Ask for the set rather than the fields:

- "track where my things came from" switches on Provenance: where each thing came from, when, and what it cost, on every physical thing the workspace tracks, now and in future.
- "turn provenance off" takes those fields away again and keeps anything already recorded in them, so switching it back on brings the values into view.

Asking for the set is not the same as building three fields by hand with those names. The set's fields carry the roles that let a scanned receipt fill them in; hand-made ones look identical on the form and stay empty.

Renaming a heading on a form works the same way as grouping: "rename the Buying heading to Purchasing".
