The edge bridge is now **install-once, add-machines-anytime**. Name it and **Install the bridge** with just a token — the box dials in and stays open. Then add machines to it whenever (in the setup dialog or later); each rides the tunnel and the running bridge configures it on the fly — **no restart, no regenerated command**. Naming the bridge is enough to install it; machines are step two, exactly as you'd expect.
