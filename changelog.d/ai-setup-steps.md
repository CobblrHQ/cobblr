Setting up AI now shows numbered steps with real links, instead of a bare box asking for a key.

## docs
Adding an AI provider used to show a dropdown and an empty field. If you did not already know where to get a key, there was nothing on screen to tell you.

Picking a provider now shows what it costs, numbered steps to follow, and a link that opens the right page. Google AI Studio, Ollama and Anthropic each carry their own. The Google steps end with pasting the key; the Ollama ones cover installing it and pulling a model that can read photos; the Anthropic ones start with adding credit, because a new account has none and a key without credit fails on first use.

Anything worth knowing before choosing is shown as a caveat rather than hidden in a step, such as the Google free tier using what you send to improve their products, and a local model being less accurate but never sending your photos anywhere.

The same steps appear whether you set AI up for a workspace under Configuration or just for yourself under your account.
