An asset's, a machine's, a purchase's and a record's built-in fields, and the form that creates a part, now lay themselves out the way custom fields already did: from what each field needs and how wide the screen is. A typed name gets a column as wide as it is, so it no longer scrolls inside a half-width box on a phone, and a create form with a field of the same name as a built-in one shows both instead of the built-in twice.
