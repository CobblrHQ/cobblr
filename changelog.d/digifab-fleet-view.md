Digital Fabrication now opens on a live **Fleet view** — every machine across all your connections on one floor, each with its current state (printing / idle / error / offline) and, when there's a Cobblr job on it, the file and a progress bar. A header counts the fleet at a glance ("12 machines · 4 printing · 1 error"), it refreshes itself, and an unreachable manager just flags its own row instead of blanking the rest. It reads what your machine managers (FDM Monster, OctoPrint, …) report — it never drives the hardware.
