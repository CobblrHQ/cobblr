**Picking a photo works the same way everywhere, and you can see the image full size before you commit.** The scan inbox had the good version: it searched using what the thing actually is (a book's title plus its author and the word "book", a car plus its paint colour), while a machine or a record page searched a plainer phrase and found worse results. Now there is one derivation, done on the server from the thing's own name and fields, so the same book searches the same way whether you are in the inbox or on its page. The picker itself is now one component everywhere: an editable search box (the derived phrase is a starting point, not a cage), bigger thumbnails, and tapping one opens it full size with a "Use this image" button, so you can tell a clean cover from a blurry re-upload before choosing it.
