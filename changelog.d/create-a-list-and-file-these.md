**Ask Cobb to make a list and file your scans into it.** Tick items in the scan inbox and say "create Mugs and file these in it": Cobb offers one plan that makes the list, kept like a kind you already have, and files the ticked items into it, with one Confirm. Undo puts the items back in the inbox and removes the empty list, and an empty list's own page now offers Remove this list.

## docs

Tick the items in the scan inbox, open Cobb and say what the list should be called and that these go in it, for example "create Mugs and file these in it". The card shows two steps: making the list (it says which existing kind it is kept like, and the fields that come with it) and filing the items you ticked. Press Confirm once and both happen. The done card's Undo files the items back into the inbox and takes the list away again while it is empty. A list with nothing in it shows "Nothing is filed in it yet" on its page with a Remove this list button.
