Without AI connected, "yes", "again", "undo" and "stop" now act on the conversation instead of apologizing: yes runs the command Cobb just offered, again re-runs the last one, undo puts its changes back, and stop waves an offer away. No model is involved; the words do what the buttons do.

## docs

Basic mode now follows the conversation. When Cobb offers a command ("I can do that: **make rack 1 through 5 in Den**"), typing **yes** or **go for it** runs it, the same as pressing Do it. After a command runs, **again** repeats it, and **undo** puts its changes back, the same as the Undo button on the message. **Stop** or **never mind** waves off an offer you did not want. All of it works with no AI connected; nothing new can be triggered this way, only the command that was already offered or already ran, through the same guarded paths as the buttons.
