## docs

**A bin from a photo.** On the Locations page, **New bin from a photo** opens the
camera. Photograph the bin, type or dictate what is in it, and the bin is
created with that name and that photo. The phrase is the name, word for word.

In the same sheet is a switch, off until you set it: **print a label for every
new bin**. With it on, a QR label is queued as soon as any bin is created, and
your label queue's auto-print setting decides whether it prints straight away or
waits with the others. If nothing prints, check that a label base URL is set
under Configuration → Labels → QR codes: automatic printing refuses without one,
because a printed QR that points nowhere cannot be fixed afterwards.
