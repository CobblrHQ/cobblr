**Open a printer's controls straight from its machine page.** The Print manager panel on a linked machine now has an **Open controls** button that opens the full cockpit (camera, temperatures, pause/resume/stop, on-printer files, and print history), the same modal a fleet tile opens. Operating a machine now feels identical whether you reach it from Digital Fabrication or from the machine's own page. The button waits until the manager is reporting the printer live (a printer it can't currently see has nothing to control).
