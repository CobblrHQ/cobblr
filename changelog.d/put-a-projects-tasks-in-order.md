**Put a project's tasks in your own order.** The arrows beside a task move it up or down, and the order stays. A new task still arrives on top, and you can ask the assistant to put one first or last.

## docs

A project's tasks stay in the order you put them. Use the up and down arrows beside a task to move it; the order is kept for everyone in the workspace. A new task arrives on top. The arrows are hidden while **Mine** is on, since some tasks are not shown there. You can also ask the assistant, for example "put sanding first".
