Connect a **Bambu Lab** printer by signing in with your Bambu account — no IP, no access code to copy. Add a connection → **Bambu Lab**, log in (region + email + password, with 2FA if you use it), and Cobblr discovers the printers on your account and pulls each one's details automatically. Cloud mode gives you live status in the fleet cockpit; the wizard tells you up front what each mode can and can't do (remote control needs LAN + Developer Mode, coming next).
