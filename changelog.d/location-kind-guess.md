The **New location** form's *Kind* is now **two labelled buttons** — **area** (a region: room, corner, workshop) and **container** (things go INTO it: bin, drawer, shelf) — instead of a dropdown, so each option's meaning is visible at a glance. It also **guesses the Kind from the name** as you type: "White Bookshelf", "Bin 17" or "Kitchen Drawer" pre-select **container**; "Storage Room" or "Workshop Corner" pre-select **area**. A small hint shows what it guessed, and tapping a button yourself always wins — the guess only sets the default so you stop choosing it by hand on every location.
