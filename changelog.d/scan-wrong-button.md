New **"This is wrong: re-check everything & fix it"** button on a scanned item. One press re-queries every source (go-upc, upcitemdb, Open Facts) plus a web search, steered by your optional "what's wrong" note, distrusts the flagged listing, reconciles the correct name + photo, and pushes the correction back to the shared barcode database so the next scan (anyone's) is right. The source panel now also shows when the listing was last updated ("10 min ago"). "Re-run AI" is unchanged.
