Returns now live on the order: start one on any line of an arrived order, follow it from Started to Refunded with one tap per stage, and the store's own return emails move the same return. When the store has it, the count comes off the shelf once, and the refund comes off the order's spend once.

## docs

On an order that has arrived, each line has a return button beside the pencil, and the order offers **Start a return**. Choose the line, how many, and why if you like. The order's **Returns** section shows each return as a row of stages: Started, Dropped off, Received by store, Refunded. Tap the next one to move it along. Refunded asks the amount, filled in with what the returned items cost.

When the store has the item (Received or Refunded), the returned count comes off the item once. Until then it still counts, and **Cancel return** is there. A refund comes off what the order cost, so total spend, the chart and a vendor's spend all net it out. If the store's email says the same thing you already recorded, nothing is counted twice, and a late email never moves a return back a stage.

You can also ask Cobb to start a return or move one along, and undo either.
