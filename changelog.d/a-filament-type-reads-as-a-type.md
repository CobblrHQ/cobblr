A filament type's page now reads as a type, not as one of its spools. It has one colour field, which can hold a blend or several colours, so a rainbow type shows as a rainbow. It no longer offers serial numbers, stock, service or lending. Its spools are listed as spools, and a Links row can't remove a spool's type. A worked-out value like "in stock" reads as plain text, and the actions at the bottom of a record never cover the field you're typing in. Each list's Going off tab now shows only that list's things.
