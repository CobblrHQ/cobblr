A filament type's page no longer offers **Set status** or **Return home**: those belong to a spool you can hold, not to a type. A new type named in one line keeps the maker's colour name, so "Polymaker PLA Royal Blue 1.75mm" is Royal Blue instead of Blue, and a colour name the browser does not know, like Fire Engine Red, still draws its swatch from its colour word.
