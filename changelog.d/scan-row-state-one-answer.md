## docs

**A row says what it needs, once, the same everywhere.** Each row in the inbox is in one of four states, and its button says which: **Add** (ready), **Install & add** (its table is a ready-made bundle you have not installed yet, and the tap installs it first), **+1 more** (you already count this thing), or **Review** (something needs a look). A row that needs a look carries one short sentence naming the problem and what to do, and the phone row, the item screen and the desktop card all show that same sentence and the same button. The session's **File N** counts exactly the rows whose button would file, and reads **Install & file N** when filing will install something. Where a row goes is remembered with who chose it: a table the system picked is swapped for a better one that appears later, while a table you picked yourself stays put, and the better table is offered beside it as a chip. Names read with a first capital ("corn starch" shows as "Corn starch"); the stored name is untouched, and a name you typed yourself is shown exactly as you typed it.

**Titles in another language** (Your account → Appearance): when a scan knows a title's original, its translation and how it is pronounced, this is how the name reads everywhere. **Original (translation)** by default, or the translation first, either alone, or the transliteration in place of the original script. Nothing is invented: a title missing a variant shows what it has.
