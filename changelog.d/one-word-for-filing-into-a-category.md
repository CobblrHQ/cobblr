Filing a whole session now uses one word for its category: "Place & file all 3 as Mugs" when it still has to ask you where, "File all 11 as Figurine" when it knows. The two used to read "as" and "into" for the very same thing, which made them look like different operations. "Into" now only ever means a place. The destination pill also comes first on an item's row even when the item has a series, so it sits in the same spot on every card.
