A book on a Bookshelf no longer dresses as groceries. Adding one book (quantity 1) used to mark the whole shelf as stock, so every book offered Use one, Used up, Threw it out, Restock and a reorder point. One of a thing is not stock now; a collection turns stock when something is counted above one, given a reorder point or a measured unit. The Bookshelf bundle also says outright that books wear no stock face, which holds on shelves that already flipped, and the parts-category picker is gone from the book form. A number field shows the number (1, not 1.000).
