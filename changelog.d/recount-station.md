Set a scan station to a recount so several tablets and phones count one collection at once, never counting a thing twice

## docs

A scan station can now be set to a recount in its settings: every scan counts a thing of that recount instead of changing stock, the screen says how far along it is and asks which one when a label could be two things. Several tablets, and phones holding the station's QR, can count one collection at once, and a thing is never counted twice.
