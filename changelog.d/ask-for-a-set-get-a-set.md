Ask Cobb for a whole set of records and he now makes them in one go. "Each rack should have Shelf 1 through 5" used to become sixty separate requests, one a second, with a spinner for two minutes; it is now a single one that takes seconds, and it arrives as one line in the chat with a single Undo that puts all of them back. Anything already there is counted and named rather than duplicated: "Added 58 locations. 2 were already there."

## docs
When you ask for a set rather than a single thing, Cobb makes the whole set in one go: "each rack should have Shelf 1 through 5", "bins A through H in the workshop". You get one line in the chat saying how many were added, with one Undo beside it that puts all of them back (it counts out loud as it works, since putting back sixty records takes a moment). Anything that was already there is counted rather than duplicated, and said plainly: "Added 58 locations. 2 were already there." Up to 200 records in a single request.
