The dashboard "at a glance" tile for a multi-type module (Machines, Assets) now lands on that module's page instead of diving into just one type. When the base list is empty but you have types like 3D Printers and Laser Cutters, the page shows those as a chooser with counts. So "Machines · 59" opens a page that actually shows printers and lasers, not just the biggest one.
