Arranging the fleet is now just dragging: no Arrange mode, no cell grid: grab any machine tile and the others shift to show where it lands, drop on the strip between rows to start a new row in place, and the layout is remembered for the whole workspace. Machines you haven't placed flow in their own trailing row, so a new printer never scrambles your floor.
