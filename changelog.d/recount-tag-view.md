A recount can cover a shared saved view (Recount this view…) or everything carrying a tag, and expects only those things, so nothing outside them is marked gone.

## docs

**Recount a view or a tag.** Open a shared saved view of a collection and the recount button reads **Recount this view…**: the recount then expects only what the view shows. A private view is yours alone and a recount belongs to the workspace, so share the view first. You can also ask Cobb to recount everything carrying a tag in a collection ("recount everything tagged garage in Tools"). Either way, only those things are expected, so nothing outside them can be marked gone, and a tag nothing carries is refused instead of starting an empty recount.
