**Hosted catalogs are now browsable.** Open a hosted catalog (Rebrickable's sets, parts, minifigs, colours, themes, part-categories) and you can scroll its entries and search them, the same as a catalog you imported yourself. The rows come from Cobblr's shared reference catalog on demand, and colours show their swatch. The one exception is the set bill-of-materials: it powers Disassemble behind the scenes and isn't meant to be paged through, so the page says so instead of looking empty.
