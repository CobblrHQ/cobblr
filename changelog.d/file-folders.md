**Files have folders now.** Make folders inside folders on the Files page, upload straight into one, rename a file or move it with "Move to…", and find any file by name from search. Uploading a file you already have keeps the one copy and says where it is, and a folder that still holds something cannot be deleted, so tidying never loses a file.

## docs

**Folders.** On the Files page, **New folder** makes a folder where you are, and a folder can hold folders ("Patterns / Blankets"). Open one by pressing it, and the path at the top takes you back up. **Upload** puts files into the folder you are looking at.

- **Rename** a file or a folder with the pencil beside it.
- **Move a file** with **Move to…** next to it, into any folder or back to the top level.
- **Delete a folder** once it is empty. While it still holds files or folders it is not deleted and tells you what is inside, so moving things around can never lose a file.
- **Find a file** with the search box on the Files page, or the app's search: both look in every folder and match the name.
- **Uploading something you already have** (the same file, even under another name) keeps the one copy and tells you which folder it is in.
