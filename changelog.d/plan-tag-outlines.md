Floor plan outlines now use workspace tag colours and names, with existing manual colours kept as a Custom option.

## docs

**Group containers on the floor plan.** In **Edit layout**, select a container and choose its **Outline group** from your workspace tags. The tag is attached to the place, its colour outlines the box, and its name appears in the legend. Changing the tag's name or colour changes the plan too. A tag with no colour gives the box a neutral outline. If several tags are attached, choose which one the plan should show.

**Keep a colour you chose by hand.** Existing manual colours still appear in the legend as **Custom**. Choose **Custom colour** or a manual swatch to use one instead of a tag's colour. Switching groups keeps the place's tags and its saved manual colour. Undo and Redo restore the previous outline group without adding the tag again.
