**A link to a list, a line on a list, or a vendor now opens it.** Search results, tags and links from Cobb pointed at addresses that opened nothing: a list's link showed the grid of lists, and a vendor's showed nothing at all. They now open the list (a line's link opens the list it is on) and the vendor, and opening a list gives it an address you can share.
