One setting names the Cobblr cloud for every share, hand-over and move to it: COBBLR_CLOUD_URL (unset is the default cloud). COBBLR_SHARE_INVITE_DESTINATIONS sets what the invite dialog offers (unset: this Cobblr and the cloud), and the api refuses to start if it names a Cobblr that is neither this one nor in COBBLR_SHARE_TRUSTED_PEERS. COBBLR_FEATURES_OFF turns a feature off by name.
