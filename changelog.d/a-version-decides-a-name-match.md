**A different version is a different thing.** A scanned Voron 0.2 kit was offered as "the same one" as a Voron 0.1 you already have, matched by name. A version or mark in the name (0.1 and 0.2, Mk3 and Mk4, V2) now tells two products apart, and the same version on both sides ranks that match first. This applies to "you already have this" and to combining two waiting scans.
