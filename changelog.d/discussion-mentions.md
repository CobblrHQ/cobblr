Type @ in a discussion to name a person, a record, or Cobb. Naming a record links the two together, both ways, using the same Linked entities you already have.

## docs

Type `@` anywhere in a discussion and pick what you mean:

- **A person** notifies them. Being named is different from something happening
  on a record you happen to follow, so it reaches you directly.
- **A record** does something more useful: it creates a real link between the
  two, visible under **Linked entities** on both. Mention three printers in a
  trade-show note and each printer now points back at the note, and the note at
  each printer. It is the same linking you can do by hand; the mention just
  saves you doing it.
- **Cobb** brings the assistant into the conversation.

**Names stay right.** A mention stores which record or person you meant, never
the name that was on screen when you typed it. Rename the printer and every
mention of it updates, everywhere, including ones written months ago.

**Editing works the way you would hope.** Take a mention out of a comment and
the link it created goes too, unless somebody else's comment still names the
same record. Links you made by hand are never touched by any of this.

**On a phone** the picker is the same: type `@`, keep typing to narrow it,
press Enter to take the highlighted one.
