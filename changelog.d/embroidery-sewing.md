Added embroidery previews, hoop and owned-thread checks, USB exports and measured thread use, plus a Sewing bundle for maintained machines, needles and pattern PDFs.

## docs

Open Embroidery in DigiFab, save the machine's usable hoops and accepted file
formats, and import a PES, DST, EXP, JEF or VP3 design. Check its preview and
map every colour stop to thread you own. Configure thread as Spool stock in
metres, or grams with grams per metre. Chart colours and nearby matches need
physical confirmation.

Prepare the USB run, download its machine filename, and follow the checklist
at the machine. Authorize that browser or tablet to start run tracking. Use the
machine's own controls to start or stop it; Cobblr does not report live status.
After the machine is idle and the needle is raised, record measured thread
metres for every colour stop and the good or scrap outcome. Interrupted work is
scrap. Retry the original outcome if a stock write fails; a spool is never
charged twice for the same run.

Install Sewing from Bundles to keep nonconnected machines as maintained
Assets, with manuals, service history and linked feet, accessories and needles.
Set needle stock to Wearing tool in hours or project uses and record use after
sewing. Import sewing pattern PDFs to see their stated supplies and sizes.
Check the fabric amount for your chosen size against the PDF and keep
corrections in Supply notes.
