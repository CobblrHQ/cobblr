**Managed apps get a cleaner header + an on-brand palette**: a locked app like "Cobblr for Yarn" now reads **"cobblr for Yarn"** in the header — the wordmark IS the "Cobblr", so it appends a short suffix instead of repeating "Cobblr for Yarn". Each managed app can also define its **own colour scheme** (the whole locked shell recolours via the same token override the admin theme uses) — Cobblr for Yarn wears a warm wool/parchment palette with a dusty-rose accent, so it reads as a yarn app, not blueprint Cobblr. Plus a casing fix: the instance sub-nav now reads "// List // Settings" (was lowercase), and BRAND.md spells out the real rule — the "cobblr" wordmark is the one intentional lowercase; everything else is sentence case.
