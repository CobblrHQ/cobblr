The live **Fleet** view (machine status, temps, progress, in-flight jobs) is now a tab right inside your **3D Printers** section — no more hunting for it under Configuration → Print Manager. It appears whenever the Print Manager is enabled, alongside the printer list. A linked printer's detail view also shows a **live status chip** (linked / connected / idle / printing % / needs-clearing / offline) so you can see state at a glance.
