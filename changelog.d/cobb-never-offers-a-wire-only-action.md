Cobb no longer offers an action that only an automation can run (one fired by an event, with its record named by the event), so "mark the task done" reaches the task itself instead of an action with nothing to act on; actions with no button on a record's page, like placing a thing in a bin, tagging it or adjusting its stock, stay Cobb's as before. Adding a field and switching on a set of fields, and a heading on a record's form and a heading in the sidebar, each now say which is which, so a request for one is not answered with the other.
