The **⌘K command palette** (and the header search bar) now find **every settings and system page**, no longer only a hand-picked few. It reads the same registry the Configuration hub uses, so anything you can reach in Configuration you can now reach by typing it: "permissions", "backup", "healthcheck", "openapi", "form builder", plus synonyms the label doesn't say ("roles" → Permissions, "audit" → Activity log). And searching **"dark mode"** (or "theme" / "night" / "light") now surfaces the **theme toggle right in the palette**: one keystroke flips your per-account light/dark preference, instead of hunting for the sidebar icon (which a branded workspace hides).
