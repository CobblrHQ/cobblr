Make a public page of your things: choose which with the same rules as a share, then give it as many links as you like, each with its own detail and its own end. Anyone with a link sees only what that link allows, with no account; revoke a link or give it a new address at any time.

## docs

**Public pages.** In Settings, Sharing, **New public page** makes a page anyone with its link can open, no account needed: your printers for a trade show, a listing.

- **What it shows** uses the same rules as a share: whole collections, things whose field says something, things one by one. Names, photos and plain fields show; prices, private notes and places stay off unless you turn them on.
- **New link** makes an address for the page. Give it a label ("Trade show", "eBay"), and optionally its own detail (this one shows prices) and an end time; at its end it stops working by itself. Each link counts its visits.
- **Revoke** stops a link at once. **New address** gives it a new one and the old one stops working.
- A stranger sees the page's things and can open each one; a link that has ended shows only "This link has expired."
