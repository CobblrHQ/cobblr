Each printer now remembers the label size loaded in it, saved with your workspace, so it is right when you come back or print from another computer.

## docs

**Each printer remembers its own label size.** Pick a size on the Labels page while
a Bluetooth printer is selected and Cobblr saves it with that printer, not with the
browser you happened to use. Come back tomorrow, or open Cobblr on another
computer, and the size is already right.

Switching printers switches the size with it, so a machine loaded with 40 x 30
stock and one loaded with 50 x 30 each keep their own setting instead of
overwriting one another. The rotate toggle is remembered the same way.

System print has no printer to remember against, so it still keeps its last choice
in the browser you use it from.
