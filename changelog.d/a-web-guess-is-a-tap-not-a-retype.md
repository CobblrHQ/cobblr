**A scanned code only the web could name is a tap, not a name to retype.** When no catalog knows a barcode (an earbuds box, a cable, a skein of yarn, a pack of batteries) and one web page names it, the card used to show that name in its note and leave the name field empty, so you typed it back by hand. Now the card asks "Is this it?" with the name as a tap, marked found on the web and not confirmed, and typing your own stays beside it. The name is never asserted for you; tapping it is your choice, the same as typing it. Names taken from a listing also read like the product rather than the listing, without the shop's name or the search engine's cut on the end.
