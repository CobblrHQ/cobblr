A try sandbox can now email you everything you made in it as one file, along with both ways to carry on: hosted by us, or running Cobblr on your own machine. The same file restores into either.

## docs

### Taking your work out of a sandbox

A sandbox deletes itself after an hour. Before it does, the bar along the bottom
offers two things, and the smaller one is the one most people want.

- **Take your work** asks only for an email address. We build a full backup of
  the workspace, email you a link to it, and show you both ways to carry on.
- **Keep this workspace** turns the sandbox into an ordinary trial instead, so
  nothing has to move at all.

What you get is a **backup**, not a template: the setup you built, every record
in it, and every file you uploaded. Restore it into a new workspace and you are
back where you left off.

Both paths accept the same file:

- **Hosted** - make a workspace, then restore the backup into it.
- **Your own machine** - install Cobblr, make a workspace, restore the same file.

Two things worth knowing:

- **The sandbox itself still ends on the hour.** Asking for the file does not
  extend it. The database is deleted exactly as promised.
- **The file is kept briefly, and only because you asked.** It lives for a few
  days so you can pick it up, then it is deleted too. If you never ask for one,
  nothing of yours is kept at all.
