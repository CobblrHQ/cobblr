You can now send someone a **premade workspace**: when minting a friend invite, tick "send them a premade workspace" and their brand-new workspace arrives already set up with a copy of your chosen workspace's configuration (modules, trackers, fields, views: no data). The join page tells them it's coming pre-configured. And if a friend sends you an exported blueprint file, "New workspace" now takes it directly, pick the file, and the workspace is built from it.
