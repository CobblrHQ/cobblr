**A feature change is one step, and it tells you what it kept.** Turning a bundle's features on or off (Designs for Yarn, Outfits for Wardrobe) is now a single change that re-applies the bundle around your collections instead of removing and reinstalling it. Afterwards the confirmation says how many records it read back in place, so "your entities stay" is checked rather than promised. A collection only a feature you turned off had set up is removed when it is empty and kept, with its records, when it is not. The activity feed records each change with what turned on, what turned off and what stayed.
