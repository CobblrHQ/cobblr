Pin a knowledge entry and it stays in the side panel on every page, so the things you keep needing are one glance away instead of one search away.

## docs

The side panel now has a **Pinned** tab beside Cobb and Discussion. Anything you
pin in the Knowledge Base shows up there, in full, on every page.

It is for the handful of things you keep needing while doing something else: a
pair of configuration codes to scan, a measurement chart, the settings that
always take three tries to remember. The body is shown complete rather than
truncated, because a code cut off after one line is a code you cannot use.

Unlike the Discussion tab, this one **does not change as you move around**. That
is the whole point of pinning: it is yours, and it is the same wherever you are.

If you have not turned on the Knowledge Base, the tab says so and links you to
it rather than sitting there empty.
