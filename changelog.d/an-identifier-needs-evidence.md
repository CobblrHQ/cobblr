A scanned item no longer gets an ISBN, serial or other identifier that nothing on it shows. A blank notebook was given another book's ISBN, found by searching for a description of it, and offered as ready to add. An identifier is now filled only from the code you scanned, text on the item, or a catalog match whose title is the one printed on it; anything else is marked as a suggestion and is not filed.
