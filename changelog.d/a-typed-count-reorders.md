**A count you type into an item now reorders like any other change.** Editing an item's quantity below its minimum, on its page or by asking Cobb, never said it was running low, so no shopping-list line or draft order followed, and the item's history had no entry for it. It now does both, the same as the − button. A recount records a history line too, marked as a correction so it never reads as use. And the + on a row that was at zero now starts a fresh lot with its use-by date, the same as every other way of adding stock, so milk put back from empty goes off on time.
