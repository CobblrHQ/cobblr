**A scan headed for an app that is not turned on shows what you can do about it.** A member used to see a plain Add, press it and read "Enable it in Configuration → Modules", a screen they cannot open. Now an owner or admin gets Install & add, which turns the app on and files the item; a member gets Ask an admin, and the request names the app; and an app that is not available here asks for another table instead.
