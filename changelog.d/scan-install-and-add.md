**Scan something you don't have a table for yet? Install the right bundle and
file it, in one tap.** When a scan's best match is a bundle you haven't installed
(scan a VIN with no Vehicles table), the confirm form now leads with an **"Install
Vehicles & add this"** card instead of quietly dropping the item into generic
Inventory. It previews the fields the scan already filled (make, VIN, year, model,
fuel…) and, in one tap, installs the bundle and files the item straight into its
new dedicated table.
