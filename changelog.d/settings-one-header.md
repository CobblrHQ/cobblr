Every settings page now wears the same header: same size, same weight, same
sentence case, with the description written in one place instead of two.
Permissions no longer prints its own title twice. On Integrations, the four
blocks share one card shape rather than three. The activity log, the background
queue and the OpenAPI browser fill the window and scroll inside it instead of
running down the page.
