**A server without Discord no longer offers to connect it.** On a self-hosted server with no Discord app or no bot to send the messages, Connect Discord appeared on the dashboard, a new collection's first steps, Your account, the account menu and a conversation, and every one of them ended on a page saying Discord was not set up. Those doors are gone there, the Discord schedule and the Discord DM binding with them. The notifications page tells a server admin, once, which settings turn it on.
