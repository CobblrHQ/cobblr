Cobb can turn a Cobblr feature on or off for your workspace when you ask for it by name, so "I want to track maintenance" sets it up instead of telling you where the switch is.

## docs

Ask for a feature the way it is written in the app:

- "turn on purchases"
- "I want to track maintenance"
- "turn off shipments, I don't use it"

Turning one on is safe to repeat: a feature already on is left alone and he says so. Turning one off takes its screens out of your navigation and keeps the records already stored, so switching it back on brings them back. The fields and automations that came with the feature are cleared out, though, so anything you tuned there is set up again from scratch. If another feature you use depends on the one you asked to remove, he refuses and names it.
