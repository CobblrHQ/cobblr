Printing to a Bluetooth label printer got a lot smoother: the media and label size pickers now show right in the toolbar (funnelled to the rolls that printer can feed) and drive the print, instead of being hidden in the printer settings. The printer connection is reused so it stops asking you to pick the device again each time, and after a print you get a reprint option to the side in case it did not come out. The preview header now reads the clean size (like 50x30mm) instead of a long decimal.
