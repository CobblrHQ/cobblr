**Photos you already took are one tap from the home screen.** An "Add photos" tile sits beside the scan shortcut on the dashboard (and a "Photos" button beside "Scan" on a new workspace's first screen). It opens the same picker the scan inbox has, so you can pick several at once; they land in the inbox as one new session with identification already running, and the page opens on that session. On Android and desktop, long-pressing the installed app's icon offers "Add photos" too.

## docs

**Photos you already took.** On the dashboard, the **Add photos** tile beside the scan shortcut opens the same picker the inbox uses (many at once; a PDF or CSV there is read as a receipt). The photos land in the inbox as **one new session** with identification already running, and the page opens on that session. A brand-new workspace has the same door as a **Photos** button beside **Scan** on its first screen. When Cobblr is installed as an app, long-pressing its icon offers **Add photos** on Android and desktop (iOS does not show app shortcuts); it opens the inbox with the picker held out as one tap.
