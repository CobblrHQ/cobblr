**The new-item form is wider, and matching a catalog fills in the fields.** The new set/part dialog now uses a two-column layout instead of one tall scrolling column, so it fits the screen. And when you match to a catalog, the entry's data flows into the fields: pick a Rebrickable set and its set number, theme, release year, and piece count fill themselves in, blanks only, so anything you already typed is kept. Which fields a catalog fills is declared on the catalog, so it works for any catalog that maps its columns to an instance's fields, not just Lego.
