**Import & export locations as CSV.** On the Locations page, Export downloads your whole location tree, and Import lets you paste/upload a CSV and **preview the exact create/update/skip diff** (and any unresolved parents) before anything writes. Generic: pick which column matches existing locations, set parent by that same column, and any extra columns are kept on the location's metadata, so you can round-trip another system's ids.
